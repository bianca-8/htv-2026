# Bundled typography

The interface uses the same font families as https://papiers.ai/:

- **CMU Serif** regular, bold and italic; **CMU Typewriter** regular. Webfont files obtained from the public `/fonts/cmu/` assets on Papiers. Original project: https://cm-unicode.sourceforge.io/. The original license is included in `CMU-LICENSE.txt`, copied from the official CTAN package at https://mirrors.ctan.org/fonts/cm-unicode.zip.
- **Geist** variable font, obtained from https://github.com/google/fonts/tree/main/ofl/geist. Its license is included in `GEIST-LICENSE.txt`.

Fonts are served locally; the UI makes no external font requests. The visual theme adapts Papiers' ivory, charcoal, muted gray and blue palette to Marginalia's existing research workflow. No Papiers logos or product imagery are bundled.
